Core Architectural Domains

Detailed breakdown of the 17 engineering modules implemented in this infrastructure.

Campus Switching

Layer 2 Switching Architecture

  • Enterprise 8-tier VLAN segmentation (VLANs 10, 20, 30, 40, 50, 60, 70, 999) with 802.1Q trunking
  • Rapid-PVST+ root bridge election and edge-port convergence optimization
  • Multi-link LACP EtherChannels providing N+1 bandwidth aggregation and member-link failover
  • Access-port defense: Port Security (sticky MAC learning), BPDU Guard (err-disabled), and Root Guard

WAN & Core Routing

Routing & Failover

  • Dual-homed eBGP peering to ISP-A & ISP-B with deterministic BGP route maps and AS-Path prepending
  • Multi-area OSPF routing (Area 0 Core Backbone, Area 50 Ashburn DR, Regional Branches)
  • Sub-second HSRP first-hop gateway redundancy with preempt tuning and priority tracking
  • BFD integration across transit links for rapid sub-second link-down neighbor state detection

Site-to-Site & Remote Access VPN

  • Cisco AnyConnect remote access VPN federated with Active Directory and Entra ID SSO
