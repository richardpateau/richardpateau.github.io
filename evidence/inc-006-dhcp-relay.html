INC-006 — DHCP Relay Failure

Network incident investigation demonstrating DHCP relay troubleshooting, Cisco IOS verification, packet analysis, DHCP server validation, remediation, and end-to-end connectivity verification.

Incident Summary

Category DHCP / Network Services
Technology DHCP Relay
Device Cisco R1
Server Cisco R2
Status Resolved

A client connected to the R1 access network was unable to obtain a DHCP address. The DHCP server was located on a different routed network, requiring R1 to operate as a DHCP relay agent.

The investigation verified the client-facing interface, DHCP relay configuration, routing to the DHCP server, DHCP server pool and bindings, packet captures, and Cisco debug output before correcting the relay configuration.

8. Root Cause

DHCP Relay Configuration Failure

The client was unable to obtain an address because the DHCP relay configuration on R1's client-facing interface was not correctly forwarding DHCP requests to the remote DHCP server.

The investigation separated the failure into multiple layers: the client had no DHCP address, R1's local interface was operational, the DHCP server had a configured pool, and packet and debug evidence showed that the expected relay/server transaction was not completing.

The before-state configuration is preserved in the repository for direct comparison with the corrected configuration.

Investigation Methodology

1. Observe

Confirmed that PC1 could not obtain a DHCP address.

2. Isolate

Verified R1 interface state, routing, DHCP server configuration, and server bindings.

3. Investigate

Inspected the DHCP helper configuration and correlated tcpdump, Wireshark, and Cisco DHCP debug evidence.

4. Remediate

Corrected the DHCP relay configuration on R1.

5. Validate

Confirmed DHCP address assignment, server-side binding, successful connectivity, and complete DHCP packet exchange.
