A client experienced loss of connectivity across an OSPF-routed path. Investigation showed that the OSPF adjacency between R1 and R2 was reaching the EXSTART state but was not progressing to FULL.

The investigation moved from routing-state verification to interface MTU comparison, OSPF interface inspection, configuration review, packet capture analysis, and finally post-remediation verification.

7. Root Cause

OSPF Interface MTU Mismatch

The OSPF adjacency between R1 and R2 was unable to progress beyond EXSTART because the connected interfaces had different MTU values. R1 GigabitEthernet0/3 was configured with an MTU of 1400, while R2 GigabitEthernet0/2 was configured with an MTU of 1500.

Both interfaces were configured for the same 10.10.20.0/30 transit network and the same OSPF Area 0, isolating the MTU difference as the relevant adjacency parameter. The mismatch prevented successful Database Description exchange and kept the OSPF neighbor from reaching FULL.

The configuration evidence is preserved in the before and after configuration files.

R1 Before Configuration → R1 Broken Configuration → R2 Baseline Configuration →

8. Remediation

MTU Corrected

The MTU on R1 GigabitEthernet0/3 was corrected from 1400 to 1500 to match the MTU on R2 GigabitEthernet0/2.

No OSPF network statements, area assignments, or IP addressing changes were required. The remediation was limited to correcting the interface MTU mismatch.

The corrected configuration is preserved as part of the incident evidence.

Investigation Methodology

1. Observe

Confirmed client connectivity failure and traceroute termination.

2. Isolate

Checked OSPF neighbor state and identified the adjacency stuck in EXSTART.

3. Verify

Compared interface MTU values, OSPF interface information, configurations, routing tables, debug output, and packet captures.

4. Remediate

Corrected the MTU mismatch on the affected interface.

5. Validate

Confirmed OSPF FULL state, route installation, successful client connectivity, complete OSPF packet exchange, and monitoring/ticket closure.
