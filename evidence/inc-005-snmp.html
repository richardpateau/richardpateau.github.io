INC-005 — SNMP Monitoring Failure

Network monitoring incident demonstrating SNMP troubleshooting, Cisco IOS verification, ACL analysis, packet capture, SolarWinds validation, remediation, and operational incident closure.

SolarWinds reported R1 as unavailable for monitoring. The initial investigation verified that the router remained reachable over IP, separating a potential device or routing failure from an SNMP monitoring failure.

The investigation then progressed through interface verification, ACL inspection, SNMP configuration review, SNMP debugging, tcpdump/Wireshark packet analysis, configuration remediation, and SolarWinds polling verification.

9. Root Cause

SNMP Configuration Failure

The investigation established that R1 remained reachable over IP, but SolarWinds could not successfully authenticate its SNMP polling requests because the configured SNMP community string did not match the expected monitoring configuration.

R1 was configured with the community string NOC-R0, using a zero (0), while the corrected monitoring configuration used NOC-RO, using the letter O. The Cisco IOS configuration, SNMP status, debug output, packet captures, and SolarWinds monitoring evidence were correlated to isolate this community-string mismatch as the cause of the polling failure.

The broken configuration is preserved in the repository for comparison against the corrected configuration.

View Broken SNMP Configuration →

10. Remediation

SNMP Configuration Corrected

The SNMP community string on R1 was corrected from NOC-R0 to NOC-RO to match the monitoring configuration used by SolarWinds.

The SNMP location and contact settings were not changed. The remediation was limited to correcting the community-string mismatch.

Investigation Methodology

1. Observe

SolarWinds reported R1 as unavailable.

2. Isolate

Verified IP connectivity from both the router and monitoring host, separating network reachability from SNMP failure.

3. Investigate

Inspected interface state, ACLs, SNMP configuration, community configuration, debug output, tcpdump, Wireshark, and Splunk.

4. Remediate

Corrected the SNMP configuration on R1.

5. Validate

Forced a SolarWinds poll and verified successful monitoring, node status, dashboard recovery, and incident closure.
