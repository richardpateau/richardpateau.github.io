INC-001 — DHCP Failure

DHCP address-assignment failure investigated using Wireshark, Cisco IOS, Splunk, and SolarWinds.

Portfolio Wireshark Incident Response Lab

Incident Summary

A client was unable to obtain an IP address through DHCP. The investigation followed an evidence-driven workflow beginning with the client symptom and progressing through packet analysis, Cisco CLI investigation, configuration review, remediation, and post-remediation verification.

Category DHCP
Protocol DHCP / UDP
Tools Wireshark / Cisco IOS
Status Resolved

Investigation

1. Client Symptom

The client was unable to obtain an IP address.

2. Packet Analysis

Wireshark showed the client transmitting DHCP Discover traffic without receiving the expected DHCP response.

3. Cisco CLI Investigation

Cisco IOS commands were used to inspect the DHCP pool, interface state, bindings, and configuration.

4. Root Cause

The DHCP configuration was incorrect for the affected subnet, preventing successful address assignment.

5. Remediation

The DHCP configuration was corrected.

6. Verification

A successful DHCP DORA exchange was observed after remediation, and the DHCP binding was populated.

Cisco CLI Evidence

Commands used during the investigation included:
