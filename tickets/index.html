Incident Workflow

01 — Report

Document the reported network symptom and affected service.

02 — Investigate

Gather CLI, packet, monitoring, and configuration evidence.

03 — Identify

Correlate evidence to isolate the technical root cause.

04 — Remediate

Apply the configuration or network change required to correct the issue.

05 — Verify

Confirm service recovery and validate the result using independent evidence.
